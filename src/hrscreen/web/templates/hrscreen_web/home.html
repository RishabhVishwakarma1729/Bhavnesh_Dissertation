Read this before relying on a result

  • A score is a similarity, not a verdict about a person. A human should review every shortlist.
  • Benchmark "relevance" is a proxy (a resume's dataset category matching the job), not a recruiter's judgement.
  • Survey pages show synthetic data until you upload real responses. Synthetic output is never a finding.
